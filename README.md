# Francis Rebouças

Moro em Belo Horizonte. Trabalho com software web e ensino Revit.

## Agora

No Revit eu ensino o arquivo inteiro, do jeito que ele precisa ficar para o projeto andar: template, detalhe executivo e família paramétrica. As aulas estão em [francisreboucas.com.br](https://francisreboucas.com.br).

No código, o que publiquei agora foi o [filter-sort-ux](https://github.com/francisreboucas/filter-sort-ux). É uma skill para agentes montarem filtro e ordenação em listas. Escrevi depois de ver a mesma tela falhar várias vezes: filtro que não combina, coluna que desfaz a ordem escolhida, estado vazio sem próximo passo. Deixei o critério escrito para o próximo agente seguir o mesmo caminho.

Mais abaixo estão os plugins de CakePHP, de 2010 a 2014. Tradução, gráfico, Ext JS, cidades do Brasil. Antigos, e ainda têm uso. Ficam no perfil.
